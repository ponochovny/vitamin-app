# Vitamin — план редизайна главного экрана

## Цель

Главный экран — это практический помощник по привычкам. Самочувствие и выполнение целей стоят выше истории питания. Записи остаются доступными внизу как подтверждение уже сделанного.

Продукт не обвиняет и не ставит диагнозы. Прогресс должен выглядеть как полезная сводка, а не как контрольная шкала.

## Типографика

- Шрифт интерфейса: **Onest Variable**.
- Заголовок страницы: 30–36 px, вес 700.
- Заголовки блоков: 18–20 px, вес 700.
- Основной текст: 15–16 px, вес 400–500.
- Метаданные: 13–14 px.
- Числа в сводке: 26–32 px, вес 700.

Название шрифта загружается локально, без внешней зависимости от Google Fonts.

## Компоновка

- Максимальная ширина контента: 1120 px.
- Основная колонка занимает 7 частей сетки, сводка — 5.
- На мобильном экране: одна колонка.
- В верхней области действует только одна заметная кнопка.
- Записи не скрываются за раскрывающимся списком.
- Микроинтерфейсы используют 44 px минимальную высоту касания.
- Радиусы: 18–24 px для крупных блоков, 12–14 px для внутренних элементов.

## Правила интерфейса

- Действие называет результат: «Додати запис», «Зберегти цілі».
- Нет pressure-мотивации и фраз типа «ты не справился».
- Цели показываются как выбранные пользователем ориентиры.
- Неизвестные составы обозначаются как оценка там, где это реализовано.
- Ошибка объясняет проблему и способ повторить действие.
- Успешная запись подтверждается коротким status-сообщением.
- Диалог открывается и закрывается в центре: меняются прозрачность и масштаб, без смещения по экрану.
- Мягкий переход только для открытия диалогов и действия пользователя.
- Механики не-анимируются при загрузке страницы.
