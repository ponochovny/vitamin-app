# Push-напоминания о приёмах пищи и настроении

Напоминания работают через устанавливаемое PWA и Web Push. Они отправляются
утром, днём и вечером по киевскому времени, если за соответствующий период не
сохранены и запись еды, и настроение. Если заполнена только одна отметка,
напоминание попросит добавить только вторую. Для каждого периода отправляется
не более одного успешного напоминания в день.

Стандартное расписание: 09:00, 14:00 и 18:00. Свой график можно задать в
настройках на странице дневника. Периоды проверки остаются фиксированными:
утро — 00:00–12:00, день — 12:00–18:00, вечер — 18:00–00:00.

## Настройка перед запуском

### Что за ключи и Edge Function

Edge Function — это небольшой серверный обработчик, который запускается
в Supabase. Функция `send-meal-reminders` вызывается по расписанию и отправляет
push-уведомления. Она работает на стороне Supabase, поэтому сайт может быть
закрыт.

Для push нужны два VAPID-ключа:

- **Публичный** сайт передаёт браузеру, когда пользователь включает
  уведомления. Его можно хранить в настройках Nuxt-приложения.
- **Приватный** Supabase использует, чтобы подписывать отправляемые push.
  Он должен оставаться только секретом Edge Function.

Сгенерируйте эту пару один раз на своём компьютере, из корня проекта:

   ```sh
   npx --yes deno run --allow-net=jsr.io scripts/generate-vapid-keys.ts
   ```

Скрипт ничего не загружает в Supabase и напечатает две строки:

- `NUXT_PUBLIC_VAPID_PUBLIC_KEY=...` — скопируйте значение после `=` в
  `.env` в корне проекта для локального запуска. Для опубликованного сайта
  задайте эту же переменную в настройках хостинга Nuxt и пересоберите сайт.
  Это публичный ключ — он предназначен для браузера.
- `VAPID_KEYS_JSON=...` — целиком скопируйте значение после `=` в секреты
  Edge Functions в Supabase. В `.env` сайта его не добавляйте.

`VAPID_CONTACT` — контакт владельца отправляющего сервера. Push-сервис
(например, Google или Apple) получает этот адрес вместе с запросом, чтобы
связаться с владельцем при проблемах или злоупотреблениях. **Письма
пользователям приложение на этот адрес не отправляет.** Укажите свою
действующую почту в формате `mailto:you@example.com`.

### Куда добавить секреты Supabase

В Supabase Dashboard откройте проект → **Edge Functions** → **Secrets** и
добавьте:

- `VAPID_KEYS_JSON` — значение из скрипта, целиком;
- `VAPID_CONTACT` — например, `mailto:you@example.com`;
- `MEAL_REMINDER_CRON_SECRET` — случайный пароль, который защищает функцию
  от вызова посторонними.

Создайте случайный пароль локально:

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
   ```

Скопируйте результат в `MEAL_REMINDER_CRON_SECRET` в Supabase Secrets и
сохраните его временно: такое же значение понадобится для настройки расписания
в Supabase Vault ниже. Не добавляйте секреты в репозиторий.

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` уже предоставляет среда Supabase
функциям. Создавать или копировать их вручную не нужно.

### Запуск

1. Примените миграцию и разверните функции:

   ```sh
   npx supabase db push --remote
   npx supabase functions deploy register-push-subscription
   npx supabase functions deploy send-meal-reminders
   ```

   `register-push-subscription` сохраняет подписку браузера, а
   `send-meal-reminders` отправляет уведомления.

2. В Supabase Vault сохраните две записи:

   - `vitamin_project_url` — URL проекта вида
     `https://<project-ref>.supabase.co`;
   - `vitamin_meal_reminder_cron_secret` — то же значение, что и
     `MEAL_REMINDER_CRON_SECRET`.

   Если расширения `pg_cron` и `pg_net` ещё не включены, включите их в
   Supabase Database → Extensions. Затем выполните
   [`meal_reminder_cron.sql`](../supabase/meal_reminder_cron.sql) в SQL Editor.

3. Запустите сайт, откройте его на телефоне, выберите время и нажмите
   «Дозволити сповіщення».

Для доставки при закрытом приложении сайт должен работать по HTTPS. На iPhone
необходимо добавить сайт на экран «Домівка» и использовать iOS 16.4 или новее.
Пока VAPID-ключи, Edge Function и расписание Supabase не настроены, push-
напоминания не отправляются.
