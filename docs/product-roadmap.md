# Дорожная карта Vitamin App

## Направление продукта

Персональный помощник по питанию и самочувствию: помогает быстро записывать еду и напитки, замечать привычки и выбирать следующие шаги к личным целям. Приложение не ставит диагнозы и не заменяет медицинскую консультацию.

### Принципы UX

- Главный экран показывает только самое важное; детали доступны по раскрытию, карточке или отдельному экрану.
- Запись должна быть простой: вес и точный состав порции не обязательны.
- Пользователь сам выбирает, какие функции отслеживать: питание, настроение, сон, вода, тренировки и челленджи.
- Напоминания и игровые механики добровольны. Пропущенный день не обнуляет прогресс и не вызывает чувства вины.
- Распознанные ИИ данные — это предложения для проверки, а не подтверждённые факты.

## Критерии готовности ключевого сценария

- [ ] Главный экран не перегружен, а подробности доступны по явному действию.
- [x] Еду можно записать без весов; приблизительная порция обозначена как оценка.
- [ ] Запись по фото требует подтверждения пользователя.
- [ ] Пометка о возможном раздражителе заметна в списке, а конкретный компонент и личная причина открываются без долгого поиска.
- [x] Цель считает только чистую воду; остальные напитки остаются в дневнике и не преобразуются в «эквивалент воды».
- [ ] Самочувствие привязано к режиму пользователя и может быть записано вне расписания.
- [ ] Персональные цели по калориям и БЖУ учитывают параметры и обычную активность пользователя, объясняют допущения и остаются редактируемыми.
- [x] Ошибки сохранения не маскируются под успешную запись; повторная отправка не создаёт дубликаты.
- [ ] Ключевые сценарии проверены на телефоне и десктопе.

## Предлагаемый порядок запуска

Сначала завершить фазы 0–3 и получить надёжный дневник с быстрым вводом. Затем добавить профиль ингредиентов и самочувствие (фазы 4 и 6), после этого — фото и напитки. Для персональных ориентиров сначала завершить ввод активности и только затем добавить расчёт целей в фазе 8. Аналитику, челленджи и PWA расширять на основе обратной связи, не откладывая при этом доступную установку PWA до самого конца, если она понадобится для первого релиза.
